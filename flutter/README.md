# Hayat Takvimi Flutter

Bu klasör Flutter ile geliştirilecek Android uygulaması için bir başlangıç iskeletidir.

## Başlangıç

1. Flutter kuruluysa proje köküne gidin:
   ```bash
   cd flutter
   flutter pub get
   flutter run
   ```

2. `lib/main.dart` dosyasını açıp uygulama ekranlarını genişletebilirsiniz.

## Önerilen paketler

- provider
- shared_preferences
- flutter_local_notifications
- geolocator
- hive
